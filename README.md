# 🐠 The Golded Fish Tank

This project is a full-featured website created as part of a study assignment. It showcases the design and implementation of a web platform for a virtual company, **The Golded Fish Tank**, which specializes in building and maintaining custom aquariums.

## 🌟 Project Overview

The website demonstrates:

- A modern, responsive design using custom CSS and web fonts.
- Informational pages about the company, its services, and legal policies (CGU, cookies, privacy).
- A contact form for customer inquiries.
- A forum and review section for user interaction and feedback.
- User authentication and account creation (frontend and backend logic).
- Example data for users, forum posts, and reviews in JSON format as a dropback when no PHP
  and / or no MySQL backend is available.
- MySQL database structure with the same sample set of datas as JSON file
- PHP backend scripts for handling login, user creation, and contact requests.
- **A dedicated SEO and marketing strategy section, outlining approaches to improve the website's visibility and attract potential customers.**

## Purpose

This repository was developed as a study project to explore the creation of a complete web solution for a fictional company in the aquarium industry. It covers both frontend and backend aspects, including user experience, data management, and basic server-side logic.  
Additionally, the project required the development of a SEO and marketing strategy to enhance the website's reach and effectiveness.
